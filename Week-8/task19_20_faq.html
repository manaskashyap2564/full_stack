What is jQuery? ▼
jQuery is a fast, small, and feature-rich JavaScript library. It makes things like HTML document traversal and manipulation, event handling, and animation much simpler with an easy-to-use API that works across multiple browsers.
How do I include jQuery in my project? ▼
You can include jQuery by downloading it from jquery.com or by using a CDN link in your HTML file. Add the script tag in the head section: <script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>
What is .slideToggle()? ▼
The .slideToggle() method displays or hides the matched elements with a sliding motion. It's a combination of .slideDown() and .slideUp(). When called on visible elements, they slide up, and on hidden elements, they slide down.
What is the .css() method? ▼
The .css() method is used to get or set CSS properties of elements. You can set a single property like .css('color', 'red') or multiple properties using an object like .css({'color': 'red', 'font-size': '20px'}).
Why use jQuery instead of vanilla JavaScript? ▼
jQuery simplifies DOM manipulation, event handling, and AJAX calls. It provides cross-browser compatibility and reduces the amount of code needed for common tasks. However, modern JavaScript (ES6+) has closed the gap with features like querySelector and fetch API.
